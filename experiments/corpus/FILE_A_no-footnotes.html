Introduction

This document is intended as a small semantic benchmark for PDF/UA generation and structure recovery. It contains headings, paragraphs, lists, links, code blocks, a blockquote, a table, a figure, and footnotes.

The main goal is to test whether common authoring pipelines preserve document structure. For a general reference, see the Markdown Guide.

Headings and Paragraphs

A structured document should preserve heading hierarchy. This paragraph contains bold text, italic text, and inline code.

Inline Semantics

Semantic preservation matters because a heading is not just larger text. A machine-readable document should retain these distinctions1.
